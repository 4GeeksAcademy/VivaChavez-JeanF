# VivaChavez - Tailwind Multi-Page Version

This submission was rebuilt to satisfy review feedback:

- Utility-first Tailwind CSS (CDN) is used across all pages.
- The previous large handcrafted CSS file was removed.
- The website is split into 5 separate HTML views.
- SEO foundations are preserved (meta tags + Schema.org).

## Stack

- HTML5
- Tailwind CSS v4 (CDN)

## 5 Required Views

- index.html
- coleccion.html
- producto.html
- carrito.html
- checkout.html

## Run locally

```bash
pip3 install flask && python3 server.py
```

Open:

- http://127.0.0.1:3000/index.html
